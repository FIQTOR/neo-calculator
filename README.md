# 🧮 React + Vite Calculator with Framer Motion

A modern, interactive, and responsive calculator application built with the latest React ecosystem. This project focuses on fast performance and an engaging user experience (UX) by incorporating smooth interface animations.

## ✨ Key Features

- **Basic Math Operations**: Supports addition, subtraction, multiplication, and division.
- **Interactive Animations**: Uses **Framer Motion** to provide satisfying visual feedback when buttons are pressed and results are rendered on the screen.
- **Lightning Fast**: Powered by **Vite** for instant build times and Hot Module Replacement (HMR).
- **Type-Safe**: Built with **TypeScript** to minimize bugs, improve developer experience, and ensure code quality.

## 🛠️ Tech Stack

- [React](https://react.dev/) - The core library for building user interfaces.
- [Vite](https://vitejs.dev/) - Next-generation frontend tooling for super-fast development.
- [TypeScript](https://www.typescriptlang.org/) - Strongly typed programming language that builds on JavaScript.
- [Framer Motion](https://www.framer.com/motion/) - A production-ready motion library for React.
